Spotify Song Popularity Prediction System

Project Overview

The Spotify Song Popularity Prediction System is a Machine Learning-based project designed to predict the popularity of Spotify songs using different audio features and song-related attributes.

Objectives

- Analyze Spotify song datasets.
- Perform data preprocessing and cleaning.
- Explore song features and popularity patterns.
- Apply Machine Learning algorithms.
- Predict the popularity of songs based on their features.

Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Project Files

- "Spotify_Song_Popularity_Prediction.ipynb" – Main project notebook.
- "dataset/" – Dataset used for prediction.
- "requirements.txt" – Required Python libraries.

How to Run

1. Clone this repository.
2. Install the required libraries.
3. Open the notebook in Google Colab.
4. Upload or connect the required dataset.
5. Run all cells to execute the project.
